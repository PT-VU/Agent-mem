# PDDL Work Memory

## Directory Layout
- `00_project_context`: 目标、范围、约束、背景资料
- `01_system_design`: 架构设计、ADR、接口、风险分析
- `02_task_management`: 阶段任务与跟踪（`phase_history` 合并里程碑与计划文件）
- `03_implementation`: 实现说明与实现阶段总结
- `04_testing`: 测试报告与回归检验（统一到 `reports`）
- `05_operations`: 运行状态、部署与运维资产
- `06_artificial_intelligence`: AI 实验、流程、日志与复盘
- `source_code`: 源代码
- `automation_scripts`: 自动化脚本
