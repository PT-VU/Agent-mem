## 2. 分组分析（按 nomem 解出率区间）

### 2.1 分组定义

| 分组 | 实例 | nomem 解出率 |
|------|------|------|
| 0% 区间 | sympy-13031、astropy-13033 | 0/10 = 0% |
| 中间区间（20–70%） | django-16139（6/10）、django-12497（6/10） | 60% |
| 100% 区间 | django-12284、sympy-24066、sympy-13551、astropy-12907、astropy-14995 | 10/10 = 100% |

### 2.2 各分组解出率对比

| 分组 | nomem | with_mem | Δ（pp） |
|------|:---:|:---:|:---:|
| 0% 区间（2 实例，20 attempts） | 0/20 = 0% | 6/20 = 30% | +30 |
| 中间区间（2 实例，20 attempts） | 12/20 = 60% | 16/20 = 80% | +20 |
| 100% 区间（5 实例，50 attempts） | 50/50 = 100% | 41/50 = 82% | **-18** |

**关键发现：**  
- 中间区间：记忆框架稳定提升解出率（+20 pp）  
- 0% 区间：存在分化——sympy-13031 实现突破（0%→60%），astropy-13033 无效果（0%→0%）  
- 100% 区间：记忆框架系统性降低解出率（-18 pp），出现天花板效应

### 2.3 特殊案例详情

**sympy-13031（突破案例）：**
- nomem：10 次全部失败（0/10）
- with_mem：10 次中 6 次成功（6/10）
- 机制：nomem 无成功轨迹可学习，理论上记忆框架无正向作用；实际结果表明 BugAntiPatternCard（失败模式记忆）指导后续 attempt 规避已知错误路径，从而实现新解法突破

**sympy-13551（干扰案例）：**
- nomem：10 次全部成功（10/10）
- with_mem：10 次中仅 5 次成功（5/10）
- 机制：该实例 nomem 已 100% 解出，引入记忆卡后 agent 被错误引导至非最优路径，解出率下降 50%（-5/10），同时 token 消耗大幅增加（见第 3 节）

**astropy-13033（无效案例）：**
- nomem 与 with_mem 均为 0/10
- 该实例对两种条件均不可解，记忆框架无法提供任何帮助

## 3. Token 消耗分析

### 3.2 分组 token 对比

| 分组 | nomem 均值 | with_mem 均值 | Δ% |
|------|---:|---:|:---:|
| 中间区间（django-16139 + django-12497） | 694,670 | 383,516 | **-44.8%** |
| 100% 区间（5 实例） | 745,967 | 861,926 | **+15.5%** |

**中间区间 token 节省的机制：** 记忆框架注入已知成功路径（BugInvariantCard + SuccessPathCard），agent 在后续 attempt 中快速收敛到正确修复方案，减少了大量无效探索步骤，从而降低 token 消耗。

**100% 区间 token 增加的原因：** 记忆引导与该实例的实际最优路径不匹配，agent 在冲突指令下反复尝试，导致 token 消耗上升。sympy-13551 是极端案例：with_mem 均值 1,983,016 token vs. nomem 832,212，增加 138.3%，对应解出率从 100% 降至 50%。

## 6. 结论汇总

### 6.1 总体效果

记忆框架在 Kimi F3 实验中总体解出率 +1.1 pp（68.9% → 70.0%），差值无统计显著性。但"总体"掩盖了方向相反的子效应：

### 6.2 分 nomem 能力区间的效果

| nomem 解出率区间 | 记忆框架效果 | 代表实例 |
|------|------|------|
| 0–70%（中间区间） | **正向**：+20–30 pp 解出率提升，−45% token 节省 | django-16139、sympy-13031 |
| 100%（天花板区间） | **负向**：−18 pp 解出率下降，+15% token 增加 | sympy-13551、sympy-24066 |

### 6.3 关键发现

1. **突破能力**：sympy-13031（0%→60%）表明记忆框架能在 nomem 完全无法解决的实例上，通过积累失败模式（BugAntiPatternCard）引导 agent 规避已知错误，从零突破至 60% 解出率。

2. **天花板效应**：5 个 nomem=100% 的实例全部出现解出率下降，平均 −18 pp。当 agent 本身已能 100% 解决问题时，引入记忆卡产生干扰而非辅助。

3. **Token 效率分化**：记忆框架对中间区间 token 节省效果显著（-44.8%），对 100% 区间则增加消耗（+15.5%），与解出率变化方向一致。

4. **无效区间限制**：astropy-13033（0%→0%）表明当实例对两种条件均不可解时，记忆框架无任何效果。

5. **时间公平性**：两组 Watchdog 触发率相近（nomem 9.9%，with_mem 9.0%），exit_status 分布相似，实验设计的公平性得到验证。
