## 实现的核心组件

### 1. Problem File数据模型
- **位置**: `agent_mem/core/problem_file.py`
- **功能**: Action级别的经验原子，包含证据指针和多视角embedding
- **关键特性**:
  - 任务ID、动作类型、意图文本、结果状态
  - 失败签名（错误类型、关键token）
  - 环境签名（工具链版本、路径哈希）
  - 证据索引（指向stdout/stderr/diff等原始输出）
  - 多视角embedding（6个视角）

### 2. Observation KG事实图
- **位置**: `agent_mem/core/observation_kg.py`
- **功能**: 记录agent执行轨迹的事实图
- **关键特性**:
  - 任务子图（task subgraph）管理
  - 两种边类型：SUCCESS_NEXT（成功链）、FAIL_RETRY（失败-重试）
  - 支持序列化/反序列化
  - 成功链和失败-重试链提取

### 3. Belief Graph信念图
- **位置**: `agent_mem/core/belief_graph.py`
- **功能**: 推断的信念和模式
- **关键特性**:
  - 原子信念（工作流模板、易错点、环境适配）
  - 尝试信念（agent决策过程记录）
  - 置信度统计和动态更新
  - 信念提升/降级机制

### 4. Multi-view Embedding多视角嵌入
- **位置**: `agent_mem/retrieval/embedder.py`
- **功能**: 为ProblemFile生成多视角embedding
- **六个视角**:
  1. 任务语义（task_sem）
  2. 文件范围（file_scope）
  3. 错误签名（error_sig）
  4. 工具输出（tool_output）
  5. 差异摘要（diff_summary）
  6. 意图（intent）

### 5. Hierarchical Retrieval分层检索
- **位置**: `agent_mem/retrieval/retriever.py`
- **功能**: 分层检索相似经验
- **两个层级**:
  - 任务级检索：相似任务的成功骨架 + 高置信workflow/env beliefs
  - Action级检索：优先检索fail_retry结构附近的相似失败-修复模式

### 6. Memory Agent内存代理服务
- **位置**: `agent_mem/retrieval/memory_agent.py`
- **功能**: 统一的内存查询和检索服务
- **五个核心能力**:
  1. Query Rewriting：自然语言任务描述改写成结构化可检索query
  2. Subgraph Selection：从KG中选择最有用的经验子图
  3. Experience Distillation：压缩为可执行建议/流程tips/约束候选
  4. Evidence Referencing：返回证据坐标，支持回放与追责
  5. Belief Update：异步更新信念统计与状态

### 7. RCA Agent根因分析
- **位置**: `agent_mem/processing/rca_agent.py`
- **功能**: 分析任务失败的根本原因
- **输出**:
  - root_cause_nodes（最小集合）
  - propagation_chain（传播链）
  - corrective_actions（修复动作模板）
  - preventive_checks（预防检查）

### 8. Error Handler错误处理器
- **位置**: `agent_mem/processing/error_handler.py`
- **功能**: 执行时修复建议生成
- **触发条件**: 执行中遇到报错/异常返回/未达预期状态
- **输出**: 基于相似失败经验的修复建议

### 9. Action Logger & KG Writer
- **位置**: `agent_mem/processing/action_logger.py`, `agent_mem/processing/kg_writer.py`
- **功能**: 执行时生成ProblemFile和写入KG

### 10. Graph Store图存储
- **位置**: `agent_mem/storage/graph_store.py`
- **功能**: 统一的图存储（Observation KG + Belief Graph）
- **MVP实现**: 基于networkx的内存存储，支持JSON持久化

### 11. SWE-agent集成适配器
- **位置**: `agent_mem/integration/sweagent_adapter.py`
- **功能**: 集成Agent-mem到SWE-agent外部工具框架
- **两个主要hook**:
  - `handle_plan_generated`：规划时经验注入（范式A）
  - `handle_action_error`：执行时出错回忆（范式B）

### 12. 主入口点和配置
- **位置**: `agent_mem_main.py`, `agent_mem/config/config_manager.py`
- **功能**: 命令行入口和配置管理

## 系统架构特点

### 1. 训练自由（Training-free）
- 无需预训练，通过在线学习积累经验
- 基于统计的信念更新，无需梯度下降

### 2. 多视角表示
- 6个互补的embedding视角
- 支持细粒度的相似性检索

### 3. 分层检索策略
- 任务级和Action级两级检索
- 优先检索失败-重试结构

### 4. 证据可追溯
- 所有建议都有证据引用
- 支持原始输出回放和追责

### 5. 信念动态更新
- 基于统计证据的置信度更新
- 信念状态提升/降级机制

## 与论文研究方向的匹配

### 研究问题（RQ）匹配
- **RQ1**: 训练自由的工作经验记忆机制有效性 → 通过ProblemFile和在线学习实现
- **RQ2**: 多视角embedding对经验检索的精度影响 → 6视角embedding和分层检索
- **RQ3**: 失败-重试结构对修复建议生成的作用 → FAIL_RETRY边和RCA分析
- **RQ4**: 信念图对长期经验积累的支撑效果 → Belief Graph和动态更新机制

### 假设（H）验证支持
- **H1**: 多视角表示能提高经验匹配精度 → 通过6视角embedding验证
- **H2**: 失败-重试结构对调试有价值 → 通过FAIL_RETRY边和修复建议验证
- **H3**: 信念图能积累可重用知识 → 通过Belief Graph和原子信念验证

## 部署和使用

### 安装步骤
1. 安装依赖：`pip install networkx PyYAML`
2. 安装agent-mem：`pip install -e .`
3. 配置SWE-agent使用bridge_hook
4. 设置环境变量指向agent_mem_main.py

### 配置示例
```yaml
# SWE-agent配置
hooks:
  - class: sweagent_ext_tools.bridge_hook.ExternalToolBridgeHook
    kwargs:
      tool_a_cmd: "python -m agent_mem_main --tool A"
      tool_b_cmd: "python -m agent_mem_main --tool B"
      timeout_sec: 5.0

# Agent-mem配置
storage:
  graph_store_dir: "./agent_mem_data/graphs"
  evidence_dir: "./agent_mem_data/evidence"
```

## 限制和已知问题

### MVP限制
1. **存储后端**: 目前仅支持内存和JSON文件，大规模使用需图数据库
2. **Embedding模型**: 使用简单文本embedding，未集成预训练模型
3. **并发安全**: 未实现多agent并发访问的锁机制
4. **性能优化**: 检索算法为基本实现，未使用向量数据库

### 已知问题
1. 依赖需要手动安装（networkx, PyYAML等）
2. 信念图的存储部分为stub实现
3. 错误处理中的检索为简化实现
