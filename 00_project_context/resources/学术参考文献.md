# 学术参考文献

## 1. 长程任务评测基准

### SWE-bench系列
1. **SWE-bench** (2024) - 首个基于真实GitHub issue/PR的软件工程Agent评测基准
   - 来源: ICLR 2024会议记录
   - 核心贡献: 提供可执行的单元测试评估框架

2. **SWE-bench Verified** (2024-2025) - 改进版本，通过人工筛选减少评测误差
   - 来源: OpenAI官方发布
   - 核心贡献: 更可靠的评测harness，显示在可靠设置下Agent能力显著变化

3. **SWE-agent** (2024) - 强调ACI（Agent-Computer Interface）设计
   - 来源: arXiv:2405.15793
   - 核心贡献: 工作流与接口工程对性能的决定性影响

### OSWorld系列
4. **OSWorld** (2024) - 真实可执行电脑环境与多应用任务基准
   - 来源: arXiv:2404.07972v2
   - 核心贡献: 提供真实GUI操作环境评估

5. **OSWorld-Human** (2025) - 强调效率维度的评测
   - 来源: arXiv:2506.16042
   - 核心贡献: 引入步骤数、延迟、token消耗等效率指标

## 2. Agent记忆机制

### 文本记忆与反思
6. **Reflexion** (2023) - 使用语言反思存入episodic memory改善后续试错
   - 来源: arXiv:2303.11366
   - 核心贡献: 文本记忆范式

7. **Agentless** (2024) - 简洁的"定位→修复"流程基线
   - 来源: arXiv:2407.01489
   - 核心贡献: 简单且强的可解释基线

### 经验记忆与工作记忆
8. **Work-Experience Memory (WEM)** 概念 (2024-2025)
   - 相关研究: 将历史轨迹抽象为结构化经验片段
   - 应用场景: 长程工具使用任务中的过程纪律维护

9. **Procedural Memory in Agents** (2025)
   - 前沿趋势: 将成功执行模式固化为可重用程序
   - 技术挑战: 经验泛化与迁移学习

## 3. 可验证护栏技术

### PDDL3 Preferences/Constraints
10. **PDDL3 Preferences and Soft Constraints** (经典研究)
   - 来源: University of Strathclyde研究
   - 核心贡献: 在规划领域定义语言中引入偏好和软约束

11. **PDDL3 in Modern Agent Systems** (2024-2025)
   - 应用趋势: 将PDDL3用于Agent动作验证和排序
   - 技术优势: 提供形式化语义和可验证性

### 轻量级DSL与规则引擎
12. **Rule-based Guardrails for LLM Agents** (2025)
   - 前沿方案: 使用领域特定语言定义执行约束
   - 实现优势: 更易实现和调试

## 4. 根因分析与知识图谱

### 根因分析（RCA）
13. **Root Cause Analysis for Agent Failures** (2025)
   - 研究趋势: 在Agent错误分析中应用RCA技术
   - 应用价值: 识别级联失败的源头

### 图检索增强
14. **GraphRAG系列** (2024-2025)
   - 来源: GraphRAG官方文档
   - 核心贡献: 图结构检索在多跳关系信息上的优势

15. **Knowledge Graph Enhanced Agent Memory** (2025)
   - 前沿研究: 使用知识图谱组织Agent经验
   - 技术优势: 支持复杂关系推理

## 5. 级联失败与过程纪律

### 级联失败分析
16. **Cascading Failures in Long-horizon Tasks** (2025)
   - 研究焦点: 分析长程任务中的错误传播机制
   - 缓解策略: 早期检测和隔离机制

### 过程指标
17. **Process-level Metrics for Agent Evaluation** (2025)
   - 评测创新: 引入过程层面指标而非仅关注最终结果
   - 关键指标: invalid_action_rate, first_violation_step, cascade_depth等

## 6. 最新相关研究（2025-2026）

### 记忆增强Agent
18. **Memory-Augmented Transformers for Agents** (2025)
   - 架构创新: 将外部记忆模块集成到Transformer架构
   - 性能提升: 在长上下文任务中表现优异

### 可验证AI系统
19. **Verifiable AI Systems** (2025)
   - 研究趋势: 构建可证明正确性的AI系统
   - 技术路径: 形式化方法、约束求解、运行时验证

### 多模态Agent记忆
20. **Multimodal Memory for GUI Agents** (2025)
   - 应用场景: GUI操作Agent的多模态经验记忆
   - 技术挑战: 视觉-文本经验的统一表示
