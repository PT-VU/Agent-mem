# PDDL_work_mem Workspace Map

This directory is the execution memory and audit space for multi-agent stage delivery.

## Directory Layout
- `PDDL_work_mem/docs/`: architecture/research/context and legacy source docs.
- `PDDL_work_mem/stage_ops/`: stage documents, verifier reports, decisions, risks.
- `PDDL_work_mem/phase_history/`: phase-level plans/reports/schedules.
- `PDDL_work_mem/tools/`: implementation workspace and tests (`sweagent_ext_tools`).
- `PDDL_work_mem/runtime/`: runtime/cache artifacts.

## Primary Source Files
- Architecture: `PDDL_work_mem/docs/开发文件/Agent-mem架构.md`
- Research baseline: `PDDL_work_mem/docs/开发文件/中文论文开题.md`
- Tool base: `PDDL_work_mem/tools/sweagent_ext_tools/`
