# 第一阶段计划（MVP阶段）

## 阶段目标
实现一个可插拔记忆模块，包含规划注入和错误纠错注入，在SWE-bench Verified上跑通并收集初步数据。

## 时间安排
- **第1周**：完成基础架构和Problem File实现
- **第2周**：实现经验抽取链路（ActionLogger, KGWriter）
- **第3周**：实现经验使用链路（Retriever, MemoryAgentService, Injector）
- **第4周**：实现异步处理模块（RCAAgent, BeliefUpdater）和集成测试

## 任务分解

### 任务1：基础架构搭建（代码工程师Agent）
1. **完善agent_mem模块结构**
   - 按照架构文档的模块清单创建核心组件
   - 目录结构：config, core, integration, processing, retrieval, storage, tests

2. **实现Problem File数据结构**
   - 定义action级经验原子的schema（参考架构文档3.1.1节）
   - 实现序列化/反序列化方法
   - 包含多视角embedding字段

3. **建立基础存储层**
   - 实现事实图（Observation KG）的基本存储和检索
   - 使用两类边：success_next, fail_retry
   - 支持跨任务子图存储

### 任务2：经验抽取链路实现（代码工程师Agent）
1. **ActionLogger实现**
   - 生成problem file + evidence pointers
   - 捕获SWE-agent事件（plan_generated, action_error）
   - 提取环境签名和错误签名

2. **KGWriter实现**
   - 写节点/边到事实图
   - 计算多视角embeddings
   - 维护证据坐标索引

### 任务3：经验使用链路实现（代码工程师Agent）
1. **Retriever实现**
   - 分层检索（task/action，multi-view）
   - 支持不同检索粒度和视角
   - 实现相似度计算和排序

2. **MemoryAgentService实现**
   - 提供query rewrite / subgraph select / distill
   - 生成可执行建议和流程tips
   - 返回证据坐标

3. **Injector实现**
   - planning/execution注入器
   - 与SWE-agent事件系统集成
   - 支持软指导和建议注入

### 任务4：异步处理模块（代码工程师Agent）
1. **RCAAgent实现**
   - 最小根因集合 + 传播链分析
   - 模仿2509.25370的"最小根因集合+传播链"范式
   - 输出修复动作模板和预防性检查

2. **BeliefUpdater实现**
   - 生成/更新attempt & atomic beliefs
   - 维护统计量（support_n, uplift, uncertainty）
   - 支持信念状态管理（active/deprecated/promoted）

### 任务5：测试与验证（检验Agent）
1. **制定测试计划**
   - 单元测试、集成测试、端到端测试
   - 性能测试和压力测试

2. **创建测试框架**
   - 使用pytest框架
   - 测试数据生成和管理
   - 覆盖率报告

3. **定义验收标准**
   - 每个模块的功能验收标准
   - 性能指标阈值
   - 集成验证标准

4. **准备测试数据**
   - 模拟SWE-agent事件数据
   - 真实任务轨迹数据（如可用）
   - 边界条件和错误场景

## 验收标准

### 功能验收
1. 系统能够捕获SWE-agent的plan_generated和action_error事件
2. 能够生成并存储problem file到事实图
3. 能够在规划阶段检索相似成功经验并提供建议
4. 能够在执行错误时检索相似失败-修复模式
5. 能够进行异步根因分析并更新信念图

### 性能验收
1. 事件处理延迟 < 100ms
2. 检索响应时间 < 200ms
3. 内存使用在合理范围内
4. 存储扩展性支持至少1000个任务

### 集成验收
1. 与现有SWE-agent框架无缝集成
2. 配置简单，易于启用/禁用
3. 日志和监控完善
4. 错误处理健壮

## 交付物
1. 完整的agent_mem模块代码
2. Problem File的schema定义和序列化/反序列化方法
3. 事实图存储实现
4. ActionLogger和KGWriter的实现
5. Retriever, MemoryAgentService, Injector实现
6. RCAAgent和BeliefUpdater实现
7. 完整的测试套件和测试数据
8. 集成验证报告
9. 性能基准测试结果

## 风险与应对

### 技术风险
1. **SWE-agent集成复杂性**
   - 应对：深入研究SWE-agent插件机制，保持接口简单

2. **多视角embedding计算开销**
   - 应对：优化embedding计算，支持缓存和批量处理

3. **事实图存储性能**
   - 应对：选择合适的图数据库或内存存储方案

### 进度风险
1. **模块依赖关系复杂**
   - 应对：明确模块接口，并行开发关键模块

2. **测试数据不足**
   - 应对：提前准备模拟数据，设计数据生成工具

### 质量风险
1. **经验检索准确性**
   - 应对：设计全面的测试用例，验证检索效果

2. **系统稳定性**
   - 应对：加强错误处理和恢复机制
