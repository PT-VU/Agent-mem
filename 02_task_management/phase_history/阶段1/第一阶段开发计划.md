# Agent-mem第一阶段开发计划 (MVP)

**制定日期**: 2026-02-18
**预计时间**: 2周（简化版）
**目标**: 实现MVP核心功能，验证基础概念

## 1. 当前状态分析

### 1.1 已有基础
- ✅ SWEAgent hook系统已实现 (bridge_hook.py)
- ✅ 外部工具调用机制已就绪 (tool_a.py, tool_b.py)
- ✅ agent_mem目录结构已创建但为空
- ✅ 架构文档和路线图详细完整

### 1.2 核心差距（根据评估报告）
- ❌ 事实图Observation KG未实现
- ❌ Problem File数据结构未实现
- ❌ 多视角Embedding未实现
- ❌ RCA分析未实现
- ❌ 信念图系统未实现

## 2. 第一阶段目标

### 2.1 总体目标
实现架构文档第12节定义的MVP核心功能：
1. problem file + evidence pointers
2. 事实图（两类边）+ 基础检索
3. execution-time fail_retry回忆修复
4. 基础RCA分析
5. 简单belief统计

### 2.2 成功标准
1. 能够记录SWEAgent的action到本地存储
2. 能够根据错误检索相似修复经验
3. 修复建议生成时间 < 2秒
4. 系统可配置启用/禁用

## 3. 任务分解（2周版本）

### 任务1：基础数据结构实现（3天）
**负责人**: 代码工程师Agent
**目标**: 实现ProblemFile和ObservationKG基础结构

**交付物**:
1. `/agent_mem/types.py` - 基础类型定义
2. `/agent_mem/models/problem_file.py` - ProblemFile数据类
3. `/agent_mem/models/observation_kg.py` - ObservationKG基础类
4. 基础单元测试（测试覆盖率 > 70%）

**验收标准**:
- ProblemFile能存储action信息、evidence pointers
- ObservationKG支持success_next和fail_retry边类型
- 类型定义完整，符合架构文档3.1-3.3节

### 任务2：简单存储系统实现（3天）
**负责人**: 代码工程师Agent
**目标**: 实现本地文件存储和基础检索

**交付物**:
1. `/agent_mem/storage/local_storage.py` - 本地JSON文件存储
2. `/agent_mem/storage/interface.py` - 存储接口定义
3. `/agent_mem/retrieval/simple_retriever.py` - 简单向量检索
4. 集成sentence-transformers进行embedding

**验收标准**:
- 能够存储和加载ProblemFile数据
- 支持基于文本相似度的简单检索
- 检索延迟 < 1秒

### 任务3：执行时修复建议实现（3天）
**负责人**: 代码工程师Agent
**目标**: 实现execution-time fail_retry回忆修复

**交付物**:
1. `/agent_mem/processing/error_handler.py` - 错误上下文提取
2. `/agent_mem/processing/fix_suggester.py` - 修复建议生成器
3. 更新现有`tool_b.py`使用新系统
4. 端到端修复测试

**验收标准**:
- tool_b能调用记忆系统检索相似错误
- 能生成简单的修复建议
- 建议生成时间 < 2秒

### 任务4：SWEAgent集成与验证（2天）
**负责人**: 代码工程师Agent
**目标**: 完整集成并验证MVP功能

**交付物**:
1. `/agent_mem/integration/sweagent_hook.py` - SWEAgent记忆Hook
2. 集成测试套件
3. 简单的配置系统
4. 性能基准测试

**验收标准**:
- 系统可配置启用/禁用
- 不影响SWEAgent原有功能
- 端到端工作流能跑通

### 任务5：检验与优化（2天）
**负责人**: 检验Agent
**目标**: 代码质量检查、一致性验证

**交付物**:
1. 代码一致性检查报告
2. 性能优化建议
3. 架构符合度评估
4. 第一阶段检验报告

**验收标准**:
- 代码符合Python最佳实践
- 架构实现符合设计文档
- 无严重性能问题

## 6. 风险与缓解

### 6.1 技术风险
- **风险**: embedding检索性能不佳
  - **缓解**: 使用轻量级模型，实现缓存
- **风险**: SWEAgent集成复杂
  - **缓解**: 最小化集成，保持hook机制

### 6.2 进度风险
- **风险**: 任务依赖导致阻塞
  - **缓解**: 项目管理Agent密切协调
- **风险**: 需求理解不一致
  - **缓解**: 定期沟通，及时澄清
