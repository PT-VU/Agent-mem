第三阶段升级工程计划（可直接指导代码更新）

版本：v1.0
适用范围：`PDDL_work_mem/source_code/sweagent_external_tools` 与 `PDDL_work_mem/06_artificial_intelligence/experiments/02_first50_unlimited`

0. 阶段目标与验收口径

阶段目标：
1. 打通 AgentMem 检索结果到模型决策的闭环
2. 提升经验质量（非占位 embedding、可执行建议、有效证据）
3. 建立可复现实验管线，支撑 with_mem/no_mem 严格对照

硬性验收（全部满足）：
1. with_mem 路径中，memory hint 出现在模型下一轮输入消息中（可在日志验证）
2. 关键实验（lite first50）可一键重跑并自动产出统一 metrics + manifest
3. 不降低成功率前提下，至少一个效率指标稳定改善：
step mean、cost total、tool failure count 三者之一达到统计上可复现改善

1. 工作分解（按优先级）

1.1 P0: 闭环注入（必须先做）

目标：让 with_mem 的检索结果进入模型下一轮上下文。

改动文件：
1. `PDDL_work_mem/source_code/sweagent_external_tools/bridge_hook.py`
2. `PDDL_work_mem/source_code/sweagent_external_tools/baseline_hook.py`
3. `PDDL_work_mem/source_code/sweagent_external_tools/tests/smoke_test.py`（或新增测试）

实现要点：
1. 在 `ExternalToolBridgeHook` 中解析 tool stdout JSON，提取 `planning_tips/repair_suggestions/evidence_refs/confidence`
2. 维护 `self._pending_memory_hints`，并实现 `on_model_query(...)`：
在下一轮 query 前向 `messages` 注入一条短格式 memory hint（长度上限、去重、低置信度过滤）
3. 加开关：
`SWE_AGENT_MEM_INJECT_ENABLED=1`（默认开）
`SWE_AGENT_MEM_MAX_HINTS`（默认3）
`SWE_AGENT_MEM_MIN_CONFIDENCE`（默认0.6）
4. baseline hook 保持不注入，仅记录，保证对照公平

验收：
1. with_mem 日志中可见 `Injected memory hints`（新增日志）
2. 下一轮 `MODEL INPUT` 可见注入内容
3. no_mem 不出现注入内容

1.2 P1: 经验质量补全（去占位）

目标：让 embedding 与建议内容可解释、可复用。

改动文件：
1. `PDDL_work_mem/source_code/sweagent_external_tools/agent_mem/processing/kg_writer.py`
2. `PDDL_work_mem/source_code/sweagent_external_tools/agent_mem/processing/action_logger.py`
3. `PDDL_work_mem/source_code/sweagent_external_tools/agent_mem/retrieval/memory_agent.py`
4. `PDDL_work_mem/source_code/sweagent_external_tools/agent_mem/retrieval/embedder.py`

实现要点：
1. `kg_writer.py`：
从 evidence pointer 读取真实 stdout/stderr/diff 内容，生成 `emb_tool_output` 和 `emb_diff_summary`，删除空字符串占位逻辑
2. `action_logger.py`：
加强 `failure_signature` 结构化提取（error_type + key tokens + stack pattern）
3. `memory_agent.py`：
过滤低价值建议（例如重复的 “Generate plan for task”）
增加建议模板的可执行字段（建议动作、预期结果、风险提示）
4. `embedder.py`：
保留 sentence-transformers 唯一后端，明确错误即失败，不降级为不可解释占位

验收：
1. `get_action_embeddings_summary` 中 `has_tool_output/has_diff_summary` 在有证据样本上为 true
2. with_mem 建议文本不再高频重复模板句

1.3 P2: 在线检索主路径升级（混合检索）

目标：在线 planning/repair 直接受益于 embedding 检索，不仅是规则匹配。

改动文件：
1. `PDDL_work_mem/source_code/sweagent_external_tools/agent_mem/retrieval/memory_agent.py`
2. `PDDL_work_mem/source_code/sweagent_external_tools/agent_mem/storage/graph_store.py`
3. `PDDL_work_mem/source_code/sweagent_external_tools/agent_mem/retrieval/retriever.py`

实现要点：
1. 在 `retrieve_for_planning/retrieve_for_repair` 中引入 embedding candidate 召回：
构造 query problem_file，调用 `graph_store.find_similar_actions(...)`
2. 建立轻量预过滤索引（内存字典）：
`error_type -> action_ids`
`action_type -> action_ids`
`file_token -> action_ids`
先过滤再做 embedding 相似度
3. 融合打分：
`final_score = a*embedding + b*rule_relevance + c*belief_confidence`

验收：
1. 检索日志包含 `candidate_count_before/after_filter`、`fused_score`
2. 与旧版对比，平均检索耗时下降、建议相关度（人工抽样）提升

1.4 P3: 事件覆盖与学习闭环补强

目标：减少被动触发，仅失败时学习的偏差。

改动文件：
1. `PDDL_work_mem/source_code/sweagent_external_tools/bridge_hook.py`
2. `PDDL_work_mem/source_code/sweagent_external_tools/agent_mem/integration/sweagent_adapter.py`

实现要点：
1. 使用 `on_action_executed` / `on_step_done` 记录成功动作摘要（低频采样，防止噪声）
2. `run_done` 的 belief update 增加质量分级：
按任务结果、工具失败率、回滚次数调整 belief 权重
3. 明确退化策略：
当 memory 置信度低或冲突大时，不注入建议

验收：
1. belief 更新日志包含质量分级字段
2. 无新增明显 token 膨胀（通过每实例 token 或 cost 对比）

1.8 P4.5: 轨迹对比分析器（新增）

目标：将 with_mem/no_mem 差异沉淀为可学习规则，而非只做结果汇总。

验收：

2. 报告可量化：分歧点数、可解释分歧比例、可复用干预模式数

4. 风险与回滚

风险：
1. 注入提示导致 token 膨胀、模型偏航
2. 检索增强后噪声建议上升
3. 指标提升不稳定（仅在少数样本有效）

回滚策略：
1. 保留 `SWE_AGENT_MEM_INJECT_ENABLED=0` 全局开关
2. 保留旧检索路径开关：`SWE_AGENT_MEM_RETRIEVAL_MODE=legacy|hybrid`
3. 每个版本打 tag，实验按 tag 固化
